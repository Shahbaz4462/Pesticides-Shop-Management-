Core change

The app now behaves like an app

The fix targets the Android experience without changing the existing business system underneath.

01 · Before

Website-like stacking

Desktop-oriented grids, nested viewport heights, and mounted sections could make a phone screen feel layered and crowded.

Risk:
hidden content, duplicated navigation, and unclear screen ownership.
02 · After

One active screen

The authenticated shell now mounts one selected module inside a dedicated screen container and transitions through explicit history state.

Outcome:
clear screen replacement, predictable back behavior, and no stale main section underneath.
