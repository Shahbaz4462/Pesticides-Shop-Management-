Shell architecture

One shell, three navigation layers

The mobile experience is organized around screen ownership, not a collection of permanently visible website sections.

01 · Contextual app bar

Compact identity, menu access, and back action.

02 · Active screen container

Mounts only the selected module in the main area.

03 · Mobile navigation

Primary actions in the bottom bar; secondary in drawer.

Permission boundary

Admin-only routes remain protected.

The shell funnels all navigation into one visible main screen.
